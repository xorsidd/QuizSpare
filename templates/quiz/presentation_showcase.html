Database Design - Core Django Models

Relational structure implemented entirely with Django ORM ForeignKey relationships.

User auth_user
  • id PK • Integer
  • username CharField(150)
  • email EmailField
  • password PBKDF2 Hashed
  • is_admin / is_staff BooleanField
Category quiz_category
  • id PK • Integer
  • name CharField(150)
  • description TextField
  • time_limit_mins PositiveInt
  • pass_percentage PositiveInt
Question quiz_question
  • id PK • Integer
  • category_id FK → Category
  • text TextField
  • marks PositiveInt(default=1)
Option quiz_option
  • id PK • Integer
  • question_id FK → Question
  • text CharField(500)
  • is_correct BooleanField
QuizAttempt quiz_quizattempt
  • id PK • Integer
  • user_id FK → User
  • category_id FK → Category
  • score / total_marks PositiveInt
  • date_taken DateTimeField
One Category → many Questions. One Question → many Options. One User → many QuizAttempts.

Slide 5 Architecture
Django MVT Pattern

Full request cycle: Browser → URL Dispatcher (urls.py) → View (views.py) → Model (models.py) → Database → Template → Response.

Slide 6 Features
Key Features

Registration & Login, Category Quizzes, Timed Quiz Attempts, Instant Auto-Grading, Personal Dashboard, Admin Manager, Leaderboard, Responsive Design.

Slide 7 Database
Relational Models

User, Category, Question, Option, and QuizAttempt tables connected via Django ORM ForeignKey fields with zero raw SQL required.

Slide 8 Workflow
End-to-End Workflow

1. Register/Login → 2. Choose Category → 3. Attempt Quiz (Timed) → 4. Auto-Submit & Grade → 5. View Result & Rank.

Slide 9 Modules
Application Modules

Student Module (attempts & history), Admin Module (manage categories & questions), Core Quiz Engine (randomization, timers, auto-submit, ranking).

Slide 10 Security
Security Considerations

PBKDF2/Argon2 password hashing, CSRF tokens, Server-side sessions, SQL injection immunity via ORM, @login_required role protection, input validation.

Slide 11 Roadmap
Future Enhancements

REST API with DRF for mobile apps, AI-based question difficulty, WebSockets multiplayer quizzes, Chart.js analytics, SMS/email alerts, PDF/Excel export.

Slide 12 Conclusion
Conclusion & Q&A

Built entirely on Python and Django, QuizSphere delivers a robust, secure, and user-friendly testing platform. Questions & Discussion Welcome.
